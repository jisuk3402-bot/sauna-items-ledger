사우나템 사입 장부 웹앱

1. ZIP 파일을 압축 해제합니다.
2. index.html을 Chrome, Safari 또는 Edge로 엽니다.
3. 모바일에서는 제품 목록의 ‘편집’을 눌러 가격·용도·비고를 입력합니다.
4. PC에서는 표의 셀을 바로 수정할 수 있습니다.
5. 입력 내용은 현재 브라우저에 자동 저장됩니다. 다른 기기로 옮길 때는 ‘백업’ 파일을 저장해 불러오세요.
6. HTTPS 웹서버에 올리면 홈 화면 설치와 오프라인 사용이 가능한 PWA로 동작합니다.

기본 입력: 제품명·이미지·업체명
빈 입력: 가격·용도·비고
